# 시나리오 03: 메모 삭제

- **우선순위:** P0 (핵심 기능, 테스트 데이터 정리 역할 겸함)
- **대상 URL:** http://localhost:3000
- **탐색 일자:** 2026-10-16 (Playwright MCP로 직접 확인)

## 목적

메모 삭제 시 확인 대화상자를 거쳐 목록에서 제거되는지 검증한다.

## 사전 조건

- 개발 서버 실행 중
- 삭제 대상 메모 존재 (시나리오 02에서 수정한 `E2E 탐색용 메모 (수정됨)`)

## 테스트 단계

| # | 동작 | 셀렉터 (Playwright) | 기대 결과 |
| - | ---- | ------------------- | --------- |
| 1 | 대상 메모 카드의 "삭제" 클릭 | `getByRole('button', { name: /E2E 탐색용 메모 \(수정됨\)/ }).getByRole('button', { name: '삭제' })` | confirm 대화상자: "정말로 이 메모를 삭제하시겠습니까?" |
| 2 | 대화상자 수락 | `page.on('dialog', d => d.accept())` | 대화상자 닫힘 |

## 검증 항목

- 목록에서 해당 메모 카드가 사라진다.
- 메모 개수가 "총 7개의 메모"에서 "총 6개의 메모"로 감소한다.
- 기존 메모 6개는 영향을 받지 않는다.

## 테스트 데이터

- 삭제 대상 제목: `E2E 탐색용 메모 (수정됨)`

## 비고 / 주의

- 삭제 확인창은 브라우저 네이티브 `confirm`이므로 Playwright에서 `dialog` 이벤트로 처리한다.
- 대화상자를 취소(dismiss)했을 때 메모가 유지되는지는 P1 시나리오로 분리한다.
