# 시나리오 02: 메모 수정

- **우선순위:** P0 (핵심 기능)
- **대상 URL:** http://localhost:3000
- **탐색 일자:** 2026-10-16 (Playwright MCP로 직접 확인)

## 목적

기존 메모의 제목을 편집하고 저장하면 목록에 변경 내용이 반영되는지 검증한다.

## 사전 조건

- 개발 서버 실행 중
- 수정 대상 메모 존재 (시나리오 01에서 생성한 `E2E 탐색용 메모`)

## 테스트 단계

| # | 동작 | 셀렉터 (Playwright) | 기대 결과 |
| - | ---- | ------------------- | --------- |
| 1 | 대상 메모 카드의 "편집" 클릭 | `getByRole('button', { name: 'E2E 탐색용 메모' }).getByRole('button', { name: '편집' })` | "메모 편집" 모달 표시, 기존 값이 채워져 있음 |
| 2 | 제목 수정 | `getByRole('textbox', { name: '제목 *' })` | 입력값 반영 |
| 3 | "수정하기" 클릭 | `getByRole('button', { name: '수정하기' })` | 모달 닫힘 |

## 검증 항목

- 목록에 수정된 제목의 카드가 표시되고, 이전 제목의 카드는 사라진다.
- 메모 개수는 변하지 않는다 (총 7개).
- 내용·카테고리는 수정하지 않았으므로 그대로 유지된다.

## 테스트 데이터

- 변경 전 제목: `E2E 탐색용 메모`
- 변경 후 제목: `E2E 탐색용 메모 (수정됨)`

## 비고 / 주의

- 편집/삭제 버튼은 카드(button) 내부에 중첩되어 있으므로, 카드 이름으로 범위를 좁힌 뒤 클릭해야 한다.
- 취소 버튼으로 편집을 닫았을 때 변경이 반영되지 않는지는 P2 시나리오로 분리한다.
